<h2>Featured projects</h2>

| Project | What it does | Stack | Live |
|---|---|---|---|
| [**clinic-appointment-scheduler**](https://github.com/Mdjamilh/clinic-appointment-scheduler) | Clinic booking with real-time availability, database-enforced double-booking protection and a FHIR R4 API | Next.js · PostgreSQL · Drizzle · Playwright | [Demo](https://clinic-appointment-scheduler-kappa.vercel.app) |
| [**carenote-ai**](https://github.com/Mdjamilh/carenote-ai) | Turns visit transcripts into editable SOAP notes, redacting PHI before anything reaches the AI | Next.js · Claude API · PostgreSQL · FHIR | [Demo](https://carenote-ai-nine.vercel.app) |
| [**guideline-rag-search**](https://github.com/Mdjamilh/guideline-rag-search) | Cited answers from preventive-care guidelines using hybrid pgvector and full-text retrieval, with evals in CI | Next.js · pgvector · Ollama · RAG | [Demo](https://guideline-rag-search.vercel.app) |
| [**medtrack-api**](https://github.com/Mdjamilh/medtrack-api) | REST API for medication schedules, dose logging and adherence reports | Express 5 · TypeScript · JWT · OpenAPI · Docker | [Docs](https://medtrack-api-sigma.vercel.app/docs) |
